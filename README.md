# Amazon Product Reviews Sentiment Analysis using NLP

## Project Overview
This is a beginner-friendly Natural Language Processing (NLP) project that classifies Amazon customer reviews into Positive, Negative, or Neutral sentiments. The project demonstrates the complete machine learning pipeline, from data exploration and text preprocessing to visualization and model building.

## Objective
The main objective is to build a simple and professional Sentiment Analysis project that can accurately classify text data using classical NLP and Machine Learning techniques.

## Dataset Information
The dataset used in this project is the **Amazon Fine Food Reviews** dataset, which consists of reviews of fine foods from Amazon. 
It has been placed in the `dataset/` directory as `reviews.csv`.

## Technologies Used
* **Python 3**
* **Jupyter Notebook**
* **Pandas & NumPy**: For data manipulation and analysis
* **Matplotlib & Seaborn**: For data visualization
* **NLTK (Natural Language Toolkit)**: For text preprocessing and VADER Sentiment Analysis
* **Scikit-Learn**: For building the Machine Learning model (Multinomial Naive Bayes)
* **WordCloud**: For generating word clouds

## Features
1. **Data Exploration**: Initial look at the dataset to understand its structure, missing values, and data types.
2. **Data Cleaning**: Handling missing values and duplicates.
3. **Text Preprocessing**: Lowercasing, removing punctuation, stopwords, extra spaces, tokenization, and lemmatization.
4. **Sentiment Analysis**: Utilizing NLTK's VADER (Valence Aware Dictionary and sEntiment Reasoner) to generate sentiment labels (Positive, Negative, Neutral).
5. **Data Visualization**: Word Clouds, Bar Charts, Pie Charts, and Histograms with business insights.
6. **Machine Learning Model**: Training a Multinomial Naive Bayes Classifier using TF-IDF vectorization to predict sentiment.

## Visualizations
The `images/` folder will contain the exported plots (to be generated by running the notebook), such as:
* Sentiment Distribution (Count Plot & Pie Chart)
* Word Clouds for Positive and Negative Reviews
* Top 20 Most Frequent Words
* Review Length Distribution

## Model Performance
The Machine Learning model utilizes **TF-IDF Vectorizer** and **Multinomial Naive Bayes**. By evaluating the model on the test dataset, we generate:
* **Accuracy Score**
* **Confusion Matrix**
* **Classification Report** (Precision, Recall, F1-Score)

## Conclusion
This project successfully applies classical NLP techniques to classify customer reviews. Through text preprocessing, sentiment analysis via VADER, and training a Naive Bayes classifier, we are able to predict the sentiment of reviews accurately. The visualizations provide valuable business insights into customer satisfaction.

## Installation Steps
1. Clone this repository or extract the project folder.
2. Navigate to the project directory:
   ```bash
   cd CodeAlpha_Sentiment_Analysis
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Download NLTK data (run in Python shell or notebook):
   ```python
   import nltk
   nltk.download('vader_lexicon')
   nltk.download('stopwords')
   nltk.download('wordnet')
   nltk.download('omw-1.4')
   ```

## How to Run
1. Open the terminal or command prompt in the project directory.
2. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Open the `notebook/Sentiment_Analysis.ipynb` file.
4. Run the cells sequentially to execute the code and see the outputs.
